# Virtual-chef

Virtual Chef is an innovative application designed to help users cook and plan meals with ease. Whether you are a novice or an expert in the kitchen, Virtual Chef provides quick access to a wide range of recipes, cooking tips, and meal planning tools, all powered by a modern user interface and voice interaction.

## Features

- **Recipe Finder:** Search for recipes based on ingredients, cuisine, or meal type.
- **Meal Planning:** Plan your weekly meals and generate shopping lists automatically.
- **Voice Interaction:** Use voice commands to search recipes, get cooking instructions, or navigate the app hands-free.
- **Text-to-Speech:** The app can read recipes and instructions aloud, helping you cook without touching your device.
- **User-Friendly Interface:** Built with PySide6 for a responsive, easy-to-use GUI.
- **Customizable Preferences:** Save favorite recipes and tailor suggestions to your dietary needs.

## Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/aanubhavv/Virtual-chef.git
   cd Virtual-chef
   ```

2. **Install the required packages:**
   ```bash
   pip install -r requirements.txt
   ```

   The main dependencies are:
   - `PySide6` - For the graphical user interface
   - `SpeechRecognition` - For processing voice commands
   - `pyttsx3` - For text-to-speech functionality

## Usage

1. **Start the application:**
   ```bash
   python main.py
   ```
2. Follow the on-screen instructions or use your voice to interact with the Virtual Chef.
